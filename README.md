# Contexto del Negocio

Las distintas empresas de transporte, turismo y comercio electrónico utilizan estrategias de precios dinámicos para ajustar el valor de productos o servicios según factores como demanda, disponibilidad o comportamiento del mercado. La implementación adecuada de este tipo de estrategias requiere sistemas con la capacidad de analizar información operativa y aplicar reglas de negocio que modifiquen los precios en tiempo real. 

Por tanto, en este caso, se busca desarrollar un motor que permita definir y aplicar reglas de pricing dinámico enfocado específicamente a una aereolínea, puesto que estas necesitan usar activamente este tipo de estrategias de precios dinámico para sus servicios.
